## Phase Goal

**As a** shopper, **I want to** browse, filter, search, sort and page through the shop's in-stock pieces in the Blacktail Archive look on desktop and phone, **so that** I can quickly find pieces in my size, brand and budget.

<objective>
Prove the whole phase on Cloudflare's runtime and hand it to the owner. CI's worker job is the only place the Worker is built and run (OpenNext cannot build on Windows), so this plan points it and the deploy smoke at /shop, opens the phase PR and gets both jobs green.

Purpose: the local proofs ran on `next start`; workerd (R2, D1 tag cache, DO queue) is where the freshness round trip, the outage path and the en-IE formatting must hold. The owner merges; the agent never does.
Output: updated ci.yml and deploy-workers.yml, the phase PR with green checks, and the end-of-phase UAT checklist.
</objective>
